# Curso sobre Git e GitHub oferecido pela plataforma de estudo Codedéx

## Conteúdos:
- git init -> inicializa um projeto acompanha pelo git.
- git remote -> gerencia as conexões com o repositório remoto.
- git branch -> renomeia o ramo para main.
- git add -> quais arquivos alterados deve ser incluido no próximo commit.
- git commit -> uma captura do código atual que ficará salvo.
- git status -> mostra os arquivos prontos, não preparados e não rastreados para o commit.
- git push -> empurra alterações para o repositório remoto.
- git clone -> clona um repositório remoto no github para a sua máquina local.
- forking -> cria uma cópia pessoa do repositório de outra pessoa, em que pode fazer alterações sem modificar o projeto original.
- git switch -> mudança de linha/branch.
- git checkout -> cria uma nova branch e muda para ela.
- git pull -> atualiza o repositório local de acordo com as mudanças do remoto.
- git merge -> mescla as branches, dependendo de qual você deseja.
